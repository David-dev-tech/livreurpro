Guide Utilisateur

Bienvenue sur LivreurPro ! Ce guide vous explique comment créer votre compte, commander une livraison, choisir votre livreur et suivre vos colis en temps réel.

Créer son compte & se connecter
01

Accéder au formulaire

Depuis la page d'accueil, cliquez sur le bouton « Démarrer ». Vous arrivez sur la page d'inscription / connexion.

02

Entrer votre adresse email

Saisissez votre adresse email. Si c'est votre première visite, un compte est créé automatiquement. Si vous avez déjà un compte, vous serez reconnecté. Dans les deux cas, un code d'accès vous est envoyé par email.

03

Saisir votre code d'accès (OTP)

Ouvrez votre boîte mail et copiez le code reçu de LivreurPro. Collez-le dans le champ de vérification, puis validez. Ce code est votre identifiant personnel — conservez-le.

04

Vous êtes connecté !

Vous arrivez directement sur le catalogue des livreurs. Votre session reste active tant que vous ne fermez pas votre navigateur.

Commander une livraison
01

Parcourir le catalogue

Rendez-vous sur la page Catalogue. Vous y trouvez tous les livreurs disponibles avec leur type de véhicule, leur capacité de charge et leur note moyenne. Utilisez les filtres (type de véhicule, poids minimum) pour affiner votre recherche.

02

Choisir un livreur

Cliquez sur « Sélectionner ce livreur » sur la carte du livreur qui vous convient. Un formulaire de livraison s'ouvre.

03

Définir les adresses sur la carte

Cliquez sur « Carte » à côté du champ Adresse de ramassage pour ouvrir la carte interactive. Recherchez votre quartier ou cliquez directement sur la carte pour placer le marqueur. Validez le point, puis faites de même pour l'adresse de dépôt.

04

Renseigner le poids et les instructions

Indiquez le poids de votre colis en kg. Le prix est calculé automatiquement selon la distance et le type de véhicule. Ajoutez des instructions spéciales si nécessaire (code porte, fragilité, etc.).

05

Confirmer la livraison

Vérifiez le prix estimé affiché, puis cliquez sur « Confirmer la livraison ». Le livreur reçoit une notification par email et votre commande apparaît dans Mes Livraisons avec le statut En attente.

Suivre ses livraisons

Accéder à l'historique

Cliquez sur Mes Livraisons dans le menu. Vous voyez toutes vos commandes avec leur statut, le livreur assigné, le prix et la distance.

Filtrer par statut

Utilisez les boutons de filtre pour afficher uniquement les livraisons En attente, En cours, Terminées ou Annulées.

Voir l'itinéraire sur la carte

Sur chaque carte de livraison, cliquez sur « Voir l'itinéraire sur la carte ». Une carte Leaflet s'ouvre avec le point de ramassage (vert), le point de dépôt (rouge) et l'itinéraire routier calculé via OpenStreetMap.

⏳ En attente — Votre commande a été enregistrée. Le livreur n'a pas encore accepté.

✅ Acceptée — Le livreur a accepté votre commande et se prépare.

🚚 En cours — Le livreur est en route vers vous ou vers le destinataire.

🎉 Terminée — La livraison a été effectuée avec succès. Réglez le livreur directement.

Gérer son profil

Modifier son nom

Accédez à Mon Profil depuis le menu. Cliquez sur « Modifier », saisissez votre nom, puis « Enregistrer ».

Supprimer son compte

En bas de la page Profil, cliquez sur « Supprimer mon compte ». Une confirmation vous sera demandée. Cette action est irréversible et supprime toutes vos données.

Conseils pratiques

Choisissez le bon véhicule : pour un petit colis léger, une moto est plus rapide et moins chère. Pour des marchandises lourdes ou volumineuses, optez pour une camionnette ou un camion.

Précisez bien les adresses : utilisez la carte pour placer le marqueur exactement à l'endroit souhaité. Ajoutez des instructions (numéro de porte, étage, point de repère) dans le champ prévu.

Paiement à la livraison : vous réglez directement le livreur en espèces à la réception de votre colis. Aucun paiement en ligne n'est requis.

Conservez votre code d'accès : il vous est envoyé par email à chaque connexion. Si vous ne le retrouvez plus, recommencez simplement le processus de connexion avec votre email.

Notez votre livreur : après chaque livraison terminée, votre avis aide la communauté à choisir les meilleurs livreurs.

Questions fréquentes
Vérifiez votre dossier Spam / Courrier indésirable. Si le mail n'y est pas, retournez sur la page de connexion et soumettez à nouveau votre adresse email pour recevoir un nouveau code.
Tant que la livraison est au statut En attente, contactez directement le livreur via son numéro de téléphone visible dans votre historique de livraisons. Une fois la livraison acceptée ou en cours, l'annulation doit être convenue avec le livreur.
Le prix est calculé automatiquement selon la distance entre le point de ramassage et le point de dépôt, multipliée par le tarif du véhicule choisi : 300 FCFA/km (moto), 400 FCFA/km (tricycle), 500 FCFA/km (camionnette), 700 FCFA/km (camion).
Assurez-vous d'avoir une connexion internet active. Rechargez la page. Si le problème persiste, essayez un autre navigateur (Chrome ou Firefox recommandés).
Le numéro de téléphone du livreur est affiché sur sa carte dans le catalogue et dans le détail de votre livraison dans Mes Livraisons. Vous pouvez l'appeler directement.
Pour l'instant, LivreurPro opère principalement à Douala. L'extension à d'autres villes du Cameroun est prévue prochainement.
