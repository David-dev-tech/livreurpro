1. PRÉSENTATION DU PROJET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LivreurPro est une plateforme web de mise en relation entre des
clients (utilisateurs) et des livreurs professionnels au Cameroun.

Zones couvertes : Douala, Yaoundé, Garoua (extensible)

Rôles dans le système :
  - Utilisateur  : s'inscrit, choisit un livreur, crée une livraison
  - Livreur      : inscrit par l'admin, reçoit et exécute les livraisons
  - Administrateur : gère les livreurs, supervise les livraisons et commissions

Serveur local recommandé : Laragon (PHP 7.4+, MySQL/MariaDB)
Base de données           : livpro
Encodage                  : UTF-8 MB4

3. BASE DE DONNÉES — SCHÉMA (livpro)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Le script complet de création est dans guide/bd.txt.

TABLE utilisateur
  id_user        VARCHAR(20) PK   — identifiant unique généré (ex: id7aB9)
  mail           VARCHAR(200)     — adresse email (unique, sert de login)
  nom_utilisateur VARCHAR(100)    — nom optionnel
  date_creation  DATETIME         — date d'inscription (NOW())

TABLE livreur
  id_livreur     INT AUTO_INCREMENT PK
  nom, prenom    VARCHAR(100)
  age            INT
  sex            ENUM('M','F')
  numero         VARCHAR(20) UNIQUE  — numéro de téléphone
  mail           VARCHAR(100)
  adresse        TEXT
  numero_cni     VARCHAR(50) UNIQUE
  carte_grise    VARCHAR(255)
  type_vehicule  ENUM('moto','tricycle','camionnette','camion')

TABLE livraison
  id_livraison      INT AUTO_INCREMENT PK
  id_user           VARCHAR(20) FK → utilisateur
  id_livreur        INT FK → livreur (SET NULL si livreur supprimé)
  adresse_ramassage TEXT            — coordonnées GPS "lat,lng"
  adresse_depot     TEXT            — coordonnées GPS "lat,lng"
  distance          DECIMAL(10,2)   — en kilomètres
  prix              DECIMAL(10,2)   — en FCFA
  poids             DECIMAL(10,2)   — en kg
  statut            ENUM('en_attente','acceptee','en_cours','terminee','annulee')
  type_vehicule     ENUM(...)
  date_creation     DATETIME
  date_validation   DATETIME

TABLE note
  id_note     INT AUTO_INCREMENT PK
  id_livreur  INT FK → livreur
  note        INT (1–5)
  impression  TEXT

TABLE commission
  id_commission   INT AUTO_INCREMENT PK
  id_livraison    INT FK → livraison
  montant         DECIMAL(10,2)   — 10% du prix de la livraison
  date_validation DATETIME

VUE utilisateur_classe
  SELECT * FROM utilisateur ORDER BY date_creation DESC

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

── CÔTÉ UTILISATEUR ──────────────────────────────────────────────

  [1] Accueil (index.html / index2.html)
        ↓ clic "Démarrer"
  [2] us_form.php
        → Si session active (id_user + mail) → redirige vers us_catalogue.php
        → Sinon → affiche le formulaire email
        ↓ soumission POST → models/inscrire_user.php
  [3] inscrire_user.php
        → Vérifie si l'email existe déjà en BD
          • Oui → récupère l'id_user existant (connexion)
          • Non → génère un id_user unique (ex: id7aB9) et insère en BD
        → Envoie un email via PHPMailer (SMTP Gmail) contenant l'id_user
        → Redirige vers views/us_otp.php
  [4] us_otp.php
        → L'utilisateur saisit l'id_user reçu par email
        ↓ soumission POST → models/verif_otp.php
  [5] verif_otp.php
        → Vérifie l'id_user en BD
        → Crée la session PHP : $_SESSION['id_user'] et $_SESSION['mail']
        → Redirige vers views/us_catalogue.php
  [6] us_catalogue.php
        → Affiche tous les livreurs depuis la BD (avec notes moyennes)
        → Filtres : type de véhicule, poids minimum
        → Clic "Sélectionner" → ouvre une modale de livraison
        → La modale contient :
            • Récap du livreur
            • Adresse de ramassage (sélection sur carte Leaflet)
            • Adresse de dépôt (sélection sur carte Leaflet)
            • Poids du colis
            • Calcul automatique du prix (tarif/km selon véhicule)
        ↓ soumission fetch() → models/traiter_livraison.php
  [7] traiter_livraison.php
        → Valide tous les champs (session, adresses, poids, prix, véhicule)
        → Insère la livraison en BD (statut: en_attente)
        → Crée la commission (10% du prix)
        → Retourne JSON { success: true, id_livraison: X }
  [8] us_livraison.php
        → Affiche l'historique des livraisons de l'utilisateur
        → Filtres par statut
        → Bouton "Voir l'itinéraire" → carte Leaflet avec marqueurs A/B

── CÔTÉ LIVREUR ──────────────────────────────────────────────────

  Les livreurs sont inscrits manuellement par l'administrateur
  (vérification physique des documents : CNI, carte grise).
  Interface livreur : liv_dashboard, liv_livraison, liv_compte, liv_note

── CÔTÉ ADMINISTRATEUR ───────────────────────────────────────────

  Accès via ad_dashboard.php (pas d'authentification implémentée à ce stade)
  Fonctionnalités :
    • ad_dashboard.php   → statistiques globales + graphiques Chart.js
    • ad_livreur.php     → liste, ajout (modale), modification, suppression
    • ad_utilisateur.php → liste des utilisateurs inscrits
    • ad_livraison.php   → supervision de toutes les livraisons

5. DESCRIPTION DÉTAILLÉE DES FICHIERS CLÉS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

config/config.php
  Définit les constantes DB_HOST, DB_NAME, DB_USER, DB_PASS.
  Crée l'instance PDO globale $pdo avec :
    - ERRMODE_EXCEPTION (erreurs SQL visibles)
    - FETCH_ASSOC par défaut
    - EMULATE_PREPARES désactivé (requêtes préparées natives)
  Utilisé via require_once dans tous les fichiers PHP nécessitant la BD.

models/inscrire_user.php
  Gère à la fois l'inscription (nouvel email) et la connexion (email existant).
  Génère un id_user de format "id" + 4 caractères alphanumériques aléatoires.
  Envoie un email HTML stylisé via PHPMailer (SMTP Gmail, port 587, TLS).
  Le contenu de l'email diffère selon inscription ou connexion.
  Redirige vers us_otp.php après envoi.

models/verif_otp.php
  Reçoit l'id_user saisi par l'utilisateur.
  Vérifie son existence dans la table utilisateur.
  Crée $_SESSION['id_user'] et $_SESSION['mail'] en cas de succès.
  Redirige vers us_catalogue.php.

models/traiter_livraison.php
  Endpoint JSON (fetch POST depuis us_catalogue.php).
  Utilise ob_start() pour éviter que des warnings PHP corrompent le JSON.
  Valide : session, id_livreur, adresses, poids > 0, prix > 0, type_vehicule.
  Vérifie l'existence de l'utilisateur et du livreur en BD avant insertion.
  Insère la livraison puis crée la commission (10%).
  Retourne { success: true/false, message: "...", id_livraison: X }.

models/proxy.php
  Proxy PHP vers l'API Nominatim (OpenStreetMap).
  Actions supportées : search (recherche de lieu) et reverse (géocodage inverse).
  Restreint les recherches au Cameroun (countrycodes=cm).
  Valide les coordonnées GPS dans les limites géographiques du Cameroun.
  Utilise cURL en priorité, file_get_contents en fallback.
  Cache HTTP de 5 minutes (Cache-Control: public, max-age=300).

models/inscrire_livreur.php
  Reçoit les données du formulaire d'ajout livreur (admin).
  Insère dans la table livreur avec requête préparée nommée.
  Redirige vers ad_livreur.php en cas de succès.
  Affiche "Element deja existant" si contrainte UNIQUE violée (numero ou CNI).

views/us_catalogue.php
  Charge tous les livreurs depuis la BD + leurs notes moyennes (JOIN).
  Affiche une grille de cartes livreurs filtrables (JS côté client).
  Modale de livraison avec deux sous-modales carte Leaflet (ramassage / dépôt).
  Calcul du prix estimé côté client : distance × tarif/km selon véhicule.
    Tarifs : moto=300, tricycle=400, camionnette=500, camion=700 FCFA/km
  Soumission via fetch() vers traiter_livraison.php (réponse JSON).
  Dépend de : css/dark/us_css.css, Leaflet 1.9.4, Font Awesome 6.4.

views/us_livraison.php
  Récupère les livraisons de l'utilisateur connecté (JOIN avec livreur).
  Affiche des cartes avec statut coloré, route A→B, méta-données.
  Filtres JS par statut (en_attente, acceptee, en_cours, terminee, annulee).
  Modale carte Leaflet pour visualiser l'itinéraire (marqueurs A/B + ligne).
  Les adresses stockées en BD sont au format "lat,lng" (coordonnées GPS brutes).

views/us_profil.php
  Interface de profil utilisateur (données statiques pour l'instant).
  Onglets : Informations, Historique, Paiement.
  Méthodes de paiement : Orange Money, MTN Mobile Money.
  À connecter à la BD pour persister les modifications.

views/ad_dashboard.php
  Tableau de bord admin avec statistiques (Chart.js).
  Graphiques : évolution des livraisons, répartition par véhicule.
  Tables : derniers utilisateurs, dernières livraisons.
  Modale d'ajout d'utilisateur (non connectée à la BD à ce stade).

index.html / index2.html
  Pages d'accueil (landing pages).
  index.html  : thème sombre (fond #050508, cyan #00D4E8) + Three.js (particules 3D)
  index2.html : thème clair (fond #F7F9FC, teal #007A8A) + Three.js (particules légères)
  Icône soleil (index.html) → lien vers index2.html
  Icône lune (index2.html) → lien vers index.html
  Sections : Hero, À propos (4 cartes), Statistiques (compteurs animés), CTA
  Animations : ScrollReveal, typewriter effect, compteurs IntersectionObserver
  Responsive : breakpoints 968px et 576px

7. CONFIGURATION ET INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cloner / copier le projet dans le dossier www/ de Laragon.

2. Créer la base de données :
   Ouvrir HeidiSQL ou phpMyAdmin et exécuter le contenu de guide/bd.txt.

3. Vérifier config/config.php :
   DB_HOST = 'localhost'
   DB_NAME = 'livpro'
   DB_USER = 'root'
   DB_PASS = ''   (vide par défaut sur Laragon)

4. Configurer PHPMailer (models/inscrire_user.php) :
   Remplacer Username et Password par vos propres identifiants Gmail.
   Le mot de passe doit être un "App Password" Google (pas le mot de passe Gmail).
   Générer un App Password : myaccount.google.com → Sécurité → Mots de passe d'application

5. Accéder au projet :
   http://localhost/livreurpro/index.html

8. POINTS D'ATTENTION ET BONNES PRATIQUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sécurité
  - Toutes les requêtes SQL utilisent des requêtes préparées PDO.
  - Les sorties HTML utilisent htmlspecialchars() pour éviter les XSS.
  - Les sessions PHP sont démarrées avec session_start() avant tout output.
  - Ne jamais committer les credentials SMTP dans un dépôt public.

Sessions
  - La session est créée dans verif_otp.php après validation de l'OTP.
  - Les pages protégées vérifient isset($_SESSION['id_user']) en début de fichier.
  - us_form.php redirige automatiquement vers le catalogue si une session est active.

Adresses GPS
  - Les adresses sont stockées en BD au format "lat,lng" (ex: "3.848,11.502").
  - Le proxy Nominatim (models/proxy.php) est requis pour la recherche de lieux.
  - Le calcul de distance côté client utilise la formule de Haversine.

Tarification
  - Le prix est calculé côté client (estimation) ET côté serveur (validation).
  - Tarifs actuels (FCFA/km) : moto=300, tricycle=400, camionnette=500, camion=700
  - Commission plateforme : 10% du prix, insérée automatiquement dans la table commission.

Emails
  - PHPMailer est configuré avec verify_peer=false (développement local).
  - En production, activer la vérification SSL.
  - L'email est envoyé à l'utilisateur ET en copie à l'adresse admin.
